# Commands for the sounds oracle (SoundsProbe / pz-dump sounds), run after the real registry was printed, on an
# emptied registry. One command per line; lines starting with '#' and blank lines are skipped. Text arguments use the
# escapes \n \t \r \\ and \uXXXX. Commands:
#   load <label> <name> <body>   GameSoundScript.Load(name, body) on the script <label> (created when new; a second
#                                load amends it); prints the exception (toString) and the script
#   scriptreset <label>          GameSoundScript.reset()
#   add <label>                  GameSounds.addSound(script.gameSound), the script is then forgotten
#   get <name> | getnull         GameSounds.getSound(name | null)
#   known <name> | knownnull     GameSounds.isKnownSound
#   cat <category>               GameSounds.getSoundsInCategory
#   volume <name> <float>        getSound(name).setUserVolume(float)
#   advanced <true|false>        SystemDisabler.setEnableAdvancedSoundOptions
#   rand <name> <seed> <n>       n times getRandomClip() with Rand's generator replaced by new Random(seed)
#   ini <text>                   writes sounds.ini into the cache folder and runs GameSounds.loadINI()
#   reset | state                GameSounds.Reset() | print the registry
#   timeline <label> <name> <body> | timelinepos <label> <marker> | timelinereset <label>
#                                SoundTimelineScript.Load | getPosition | reset
#   rpm <label> <name> <body> | rpmreset <label>
#                                VehicleEngineRPM.Load | reset
